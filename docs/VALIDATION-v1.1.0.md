## 待用户实机验证

1. 左手、右手各做单击/右击/窗口标题栏拖拽；单击后继续移动是否自然，松开/暂停是否立即释放。
2. 正面、侧面、背面和旋转姿态，只在目标手指可见时测试；记录模型丢失、误分类与编号稳定性，不要求遮挡条件下继续控制。
3. 食指/双指微动是否够用、静止或轻微抖动时是否稳；调节光标灵敏度和防抖强度，记录舒适值。
4. Chrome/Edge长网页与至少一款PDF阅读器，持续滚动5分钟，验证方向、停手停止；Ctrl+Q只发送一次，Ctrl+Alt+G在其他窗口聚焦时可暂停。
5. 普通权限、100%/125% DPI、相机占用/拔插和30分钟连续运行；记录CPU/内存增长、异常和准确率。点击成功率≥90%、端到端P95<150ms仍是待测目标。

三维旋转的合成测试验证算法不依赖固定朝向，不能证明 MediaPipe 在真实任意角度或严重遮挡时都能正确估计关节。此版可试用，尚未完成人工体验验收。
