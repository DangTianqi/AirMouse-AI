# AirMouse AI · 论文阅读助手

Windows 使用说明 · v1.10.0 · 左手、右手均可，每次跟踪一只手

## 1. 启动

摄像头识别手指，控制主显示器上的光标、滚动、左右键及 Ctrl+Q；五指张开触发任务视图，继续左右/下划操作虚拟桌面和显示桌面。无需账号、Python 或联网，不录制或上传相机画面。

- 适用 Windows 10/11 x64，需要内置或 USB 摄像头；本次实际构建系统为 Windows 构建26220，其他系统仍需兼容性复测。
- 完整解压 ZIP，双击 AirMouseAI 文件夹里的 AirMouseAI.exe。保留 _internal，不要只复制 EXE，不要在压缩包中直接运行。
- 确认标题为 v1.10.0，退出旧版再启动新版。
- 启动默认“已停止”。选择摄像头编号，点击“开始”，等待初始化。0 是默认候选，不成功可停止后尝试1、2；列表不是实际设备枚举。
- 先用实体鼠标点击目标阅读窗口，使其获得焦点。助手可最小化运行。开启置顶悬浮窗后，主窗口最小化仍可看到画面；两处预览都不可见时跳过预览绘制。

## 2. 五指与检测反馈

预览默认有彩色关节点、骨架和固定编号，左右手一致。

| 编号 | 手指 | 用途 |
| --- | --- | --- |
| 1:T | 大拇指 | 功能键：配合食指按住左键；改变滚动方向；配合小指右击 |
| 2:I | 食指 | 单独伸出移动；与中指滚动；与拇指捏合 |
| 3:M | 中指 | 单独伸出移动；与食指或无名指滚动 |
| 4:R | 无名指 | 单独伸出移动；与中指滚动；与小指发送 Ctrl+Q |
| 5:P | 小拇指 | 伸出或接近伸直即锁定光标，收拢确认后恢复；参与右击、Ctrl+Q或独立五指命令 |

HAND TRACKED 表示检测到手，NO HAND 表示未检测到；3D 表示使用世界三维关节，IMAGE XYZ 表示图像三维关节。骨架存在不代表当前手形能触发命令，请同时看“当前动作”。

左右手、正面、侧面、背面使用同一组手指身份与几何规则，不要求掌心固定朝向。保持目标手指可见；严重遮挡、出画、极端侧转或模型失效时无法保证识别。换手会重新稳定识别；按住左键时换手会先释放。

## 3. 手势速查

除表内指定的手指外，其余手指收起；滚动时小指状态不限。小指采用伸出/收拢分开判定：自然伸直或接近伸直就锁定移动，临界识别状态保持锁定；明确收拢连续约0.12秒后才恢复。无需把小指绷到笔直。首次进入移动与滚动先稳定约0.15秒。单指已确认后，轻微弯曲进入临界区会继续跟随，明确收起、换手势或失联则退出；小指锁定立即生效。放松手臂，小幅活动手指即可。

| 操作 | 手形与动作 | 结果 |
| --- | --- | --- |
| 移动鼠标 | 单独伸食指、中指或无名指中的任意一根，轻微活动该手指 | 指尖相对指根的位移控制光标；拇指、小指单独伸出不移动 |
| 找回光标 / 回中 | 五指全部收起握拳，拇指也收拢，保持约0.5秒 | 光标一次回到主屏幕中心；然后收起其他手指，用食指/中指/无名指中的一根重新开始移动，无需画圈 |
| 停止移动 | 小指自然伸出或接近伸直 | 立即锁定普通光标/拖动位移；临界状态不放行。明确收拢约0.12秒后重新锚定，不追赶旧位置 |
| 向上滚动 | 伸食指＋中指，或中指＋无名指，拇指收起；两指一起弯曲 | 弯曲产生向上滚动，停住即停；伸直复位不反向滚动 |
| 向下滚动 | 同样两组双指，再加拇指伸直；两指一起弯曲 | 弯曲产生向下滚动；其他手指收起 |
| 左键单击 | 拇指、食指轻捏后松开，中指与无名指收起 | 确认轻捏约65毫秒后按下左键；松开约40毫秒后释放，形成一次单击 |
| 按住左键 | 保持拇指、食指轻捏 | 持续按住左键；前1秒冻结光标，不重复点击 |
| 拖动窗口或选择内容 | 先定位到标题栏/起点，轻捏保持超过1秒，再移动两指捏合中点 | 保持按住左键并移动；松开即释放。持续时间从开始捏合计算 |
| 右击 | 拇指＋小拇指伸直，食指、中指、无名指收起，稳定约0.18秒 | 在当前光标处右击一次；保持不会连发 |
| 五指张开 | 五指全部伸直张开，确认约0.12秒，无需划动 | 直接触发一次任务视图，保持不反复触发 |
| 五指左右划 | 已张开五指后，继续向左或右划 | 切换左侧或右侧虚拟桌面，不移动光标 |
| 五指下划 | 同一五指手形，共同向下划 | 显示桌面；再次完整下划可还原窗口 |
| 发送 Ctrl+Q | 无名指＋小拇指伸直，拇指、食指、中指收起，保持约0.8秒 | 只发送一次 Ctrl+Q；该组合专用，不参与滚动 |

五指桌面操作：五指张开确认约0.12秒后，先触发一次任务视图，取消上划动作。保持五指不动不会反复开关任务视图；继续保持这次手形，还可向左、右或下划动一次。之后明确换其他有效手形至少0.3秒，再张开五指开始下一轮。失联、暂停或识别临界/模糊不算放松，不会绕过防连发。

方向按镜像后的画面计算，左右手均可。拇指保持伸开即可，不要求与长指移动完全相同距离；无需大幅摆臂。轻抖、只动一根、明显斜划不应产生左右/下划命令。上划不再发送额外命令，也不会用它重复触发任务视图。

五指模式仍锁定普通光标与捏合拖动位移，小指停止规则不拦截这组独立命令。旧版四指伸直、拇指收起的桌面手势已取消；无名指＋小指仍只发Ctrl+Q，握拳仍回中。

五指使用软件内置映射：左/右为Win+Ctrl+←/→，张开五指为Win+Tab，下为Win+D。不是虚拟触控板驱动，不自动读取Windows触控板自定义映射；不包含五指轻点或音量/媒体控制。切桌面前需要已有至少两个虚拟桌面，未创建或到边界时系统可能没有切换效果；不会自动创建/关闭桌面。Win+Tab具有打开/收起任务视图的切换行为，保持同一次张手不重复发送；Win+D具有显示/还原桌面的切换行为。实体修饰键或目标键已按住时跳过发送并提示未发送，松开实体键，换其他手形0.3秒后重做。

首次Ctrl+Q可直接做目标手势，无需先做其他姿态。再次触发右击或Ctrl+Q前，换成其他有效手形至少0.3秒。旧版食指＋小指组合已取消。

小拇指停止键只作用于普通光标和拖动的位移，不阻断滚动、左键按下/释放、右击或Ctrl+Q。滚动仍只检查食指＋中指、中指＋无名指两组，小指伸直或收起均可；方向只由拇指决定，不按总指头数判断。无名指＋小拇指即使加入拇指也不成为滚动组合。切换滚动方向后需稳定，再继续弯曲；单纯切换拇指不会突然产生滚动。

回中已改为握拳，原五指张开手势不再回中。五指都要收拢，包括拇指和小指；小指只是半弯还没收拢时不会当成完整握拳。握拳保持只触发一次；先换成其他有效手形至少0.3秒，再握拳保持0.5秒可再次触发。短暂握拳不足半秒不会回中。失联、暂停后继续握拳不会重复触发，先伸开再重做。捏合拖动时握拳会先释放左键，再回中。

捏合按住期间明确伸直小拇指，只冻结移动，左键仍按住；收回小指会在当前位置重新建立移动锚点。要释放左键，松开拇指食指或暂停。捏合过程中仍需让中指、无名指收起。

普通移动采用手指相对指根的微动，抵消整手平移；拖拽采用捏合中点位移，可小幅移动保持捏合的手。默认镜像，画面中向左运动对应光标向左。重新进入或换移动手指时会从当前光标位置建立锚点。轻动用于精调，快速划动会自动增加行程；不需要通过大幅摆手获得快速移动。新滤波按采样时间工作，减少15–30 FPS切换引起的手感差异。实体鼠标和触控板仍可使用，检测到外部光标位移后从新位置重新锚定，避免拉回旧位置。

Ctrl+Q会显示确认百分比；短暂的临界识别帧最多约0.12秒只暂停计时，不立即清零，长时间不确定会重新计时，始终不明确则不发送。拇指自然收拢即可，不要求刻意折弯；明确伸出拇指不会发送。确认有效识别累计约0.8秒后只触发一次。

Ctrl+Q 仅发送组合键，软件不赋予退出、关闭或翻页含义，实际效果由目标应用决定。实体 Ctrl、Shift、Alt、Windows 或 Q 键被按住时跳过发送，并明确提示“未发送”；放松实体键和手势后重做。先让目标阅读窗口获得焦点，实际效果由该窗口决定。

松手、跟踪丢失、捏合姿态破坏、换手、暂停、停止、错误或正常退出会释放本程序按住的左键。跟踪恢复后先张开捏合，再重新轻捏，避免恢复时误按。持续有效捏合没有固定时长上限。

## 4. 暂停与低资源设置

- Ctrl+Alt+G 或“暂停”：停止输入，关闭相机并回收模型进程；再次按快捷键或点击“继续”恢复，需要短暂初始化。已停止时快捷键不会开启相机。
- “停止”：停止并释放资源；之后可点“开始”。右上角“×”：完全退出，不驻留托盘。
- 建议初值：“精细定位”、镜像、预览、骨架开启，识别上限24 FPS；光标向上1.8×、向下1.3×，向左/向右各1.0×，滚动默认2.0×，防抖1.0×。
- “精细定位”默认开启：连续明确的微动可输出1像素小步，降低慢速增益，快速运动仍加速；切换开关重新锚定，六项倍率不会被重置。可关闭对比普通响应，开关会保存。若某方向已设为高倍率，小目标仍难定位，可降低该方向倍率；建议防抖先用1.0×。
- 光标向上仍吃力：提高“光标向上”，不用提高其他方向；四个方向按屏幕实际方向计算，镜像开关不会把向左/向右倍率弄反。方向倍率同样适用于捏合拖动。
- 向上0.6–10.0×、向下0.5–9.9×，左/右、滚动和防抖0.5–10.0×，步进0.1×。上下会自动联动，保证向上至少比向下高0.1×：提高向下时必要时提高向上，降低向上时必要时降低向下；向上到10×时向下最高9.9×。自动保存，不叠乘总倍率。
- 抖动较明显：改善光照，提高防抖或降低对应方向倍率。防抖在速度放大前执行；防抖过高会忽略微小有意动作。先用防抖1.0×试用，觉得费力时不要继续提高防抖。普通响应采用自适应位置滤波和连续软死区；精细定位会识别持续同向的微动，降低对应轴的微动门槛，保留小数像素累计为整像素输出；同距离快划比慢动走得更远。10×仍受屏幕边界与3600像素/秒安全上限约束（24 FPS约150像素/次、30 FPS约120像素/次），以减少突跳。
- 降低CPU：关闭主窗口预览与悬浮窗，或识别上限调至15/20 FPS。只关闭主窗口预览时，已开启的悬浮窗仍会取画面；暂停/停止才回收视觉进程。
- 队列和预览缓存有界，不积压画面；骨架绘制限频10 FPS。实际短时内存和速度见随包“测试验证记录.md”，不同机器会有差异。
- 升级v1.3默认上下设置时，1.6×/1.0×改为1.8×/1.3×；其他自定义值尽量保留，并自动校正为向上更高。更早统一倍率按上1.8倍、下1.3倍、左右原值迁移。保存后不会重复放大；预览等偏好保留。
- 滚动默认2.0×；升级时旧版默认1.0×会一次性迁移到2.0×，其他自定义值保留。升级后仍可手动改回1.0×，重启不会再次改动。
- 光标上/下/左/右、滚动、防抖共6项倍率，每行右侧均有数字输入框。点击数字可直接键入，例如2.5，按回车或移开焦点后生效，滑块同步；拖动滑块也同步数字。输入保留一位小数、步进0.1×，范围与滑块一致，上下联动规则仍有效；非法/超范围文本不会保存成无效倍率。
- 五指模式会显示缺少哪根手指、确认百分比、任务视图手势触发和后续划动进度。短暂临界识别约0.12秒内保留起点，不把不确定时间计入确认；持续识别不稳会重新建立起点。
- 设置自动保存。方向滑块位于“滚动速度”下方；小窗口向下滚动即可看到全部控制项。相机预览按比例显示，不裁切指尖。

## 5. 置顶悬浮小窗

- 在主窗口勾选“置顶悬浮小窗”，就会显示独立小窗。取消勾选或点击小窗右上角“×”可关闭；开关会保存。打开小窗本身不会开启摄像头。
- 小窗显示同一摄像头的骨架画面、运行状态与当前动作，始终置顶于普通桌面窗口，不会因主窗口最小化而消失。不另开相机或另一套识别。
- 按住小窗标题栏拖动到喜欢的位置；拖边框或四角调整大小，最小240×240。画面按比例完整显示。位置与大小自动保存，重开保留；原显示器移除后会调整回可见屏幕。
- 小窗的“开始/暂停/继续”按钮控制同一个识别任务；“主窗口”按钮恢复主窗口以调整参数。
- “主窗口预览”只控制主窗口，小窗可单独显示画面。主窗口最小化时只绘制可见小窗；两窗都最小化或不显示预览时不再绘制，识别仍继续。
- 关闭小窗不会停止手势控制或关闭摄像头；需要释放资源，用“暂停/停止”或Ctrl+Alt+G。关闭主窗口则完全退出，并一起关闭小窗。
- 下次启动会恢复小窗开关和布局，但摄像头仍默认停止，需要点击“开始”。独占全屏应用可能需切换为窗口或无边框模式，才能正常叠加桌面悬浮窗。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 相机打不开 | 停止后关闭其他占用相机的软件，检查Windows相机/桌面应用权限，重插USB或更换编号 |
| 有画面无骨架 | 勾选“骨架与手指标识”，保持手完整可见并改善光照；NO HAND意味着模型尚未跟踪到 |
| 侧面/背面不稳 | 放慢旋转，减小遮挡，略微调整角度；几何算法无法补回模型没有检测到的指尖 |
| 弯曲双指没有滚动 | 先伸直正确双指并稳定，再一起弯曲；每次伸直复位后才能再次弯曲，停住不会持续滚动 |
| 单击没释放 | 张开拇指食指，检查当前动作；也可用暂停立即释放。单击是轻捏后松开，持续捏住则持续按住 |
| 拖动不动 | 保持捏合超过1秒，再移动捏合点；前1秒与小拇指明确伸直时冻结。向上困难可单独提高向上倍率 |
| 小窗不显示画面 | 确认已开始识别；仅开启小窗不会自动打开摄像头。主窗口预览关闭不影响已开启的小窗 |
| 找不到光标 | 五指全部收起握拳并保持半秒；回中后收起其余手指，单独伸食指/中指/无名指重新建立锚点 |
| 光标费力、不跟手 | 先把防抖调回1.0×，保持手指在画面中清晰可见；轻动精调、快划跨越较远距离，方向倍率仍可独立调节。已确认的单指可略弯，完全收起则退出；不必持续绷直 |
| 向下倍率不能设为10× | 向上必须更高且最高10×，所以向下最高9.9×；调节时上下会自动联动 |
| 小指收起后仍短暂不能移动 | 临界识别状态保持锁定，需要明确收拢约0.12秒后恢复；同时检查当前是否仍为合法单指移动手形 |
| 右击不触发 | 仅拇指和小拇指伸直，其余三指收起；先放松0.3秒再重做，不使用旧版拇指中指捏合 |
| 五指命令没响应 | 五指均伸直张开，拇指也伸开；约0.12秒确认后直接触发任务视图，无需上划；重复前换其他手形0.3秒。看小窗的缺少手指、确认、划动进度及发送反馈；切桌面需先有多个虚拟桌面。实体按键占用时会提示未发送 |
| Ctrl+Q不触发 | 伸无名指与小指、其余自然收起，看确认百分比；首次可直接保持约0.8秒。提示识别不稳时调整可见角度；“未发送”则松开实体修饰键或Q后重做。重复前先放松手势0.3秒 |
| 目标窗口不响应 | 用实体鼠标使其获得焦点；试其他阅读器。普通权限程序无法保证控制高权限窗口 |
| 暂停热键无效 | 检查是否提示热键注册失败，可能被其他软件占用；可用界面按钮 |
| 模型/DLL缺失 | 完整重新解压，保持 EXE 和 _internal 的相对位置，避免混用新旧版本 |

配置：%LOCALAPPDATA%\AirMouseAI\config.json；日志：同目录 airmouse.log（有大小和轮转限制）。恢复默认：退出后重命名配置文件再启动。卸载：退出后删除解压目录；需要时另删上述设置目录。
