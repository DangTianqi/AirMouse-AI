# AirMouse AI v1.10 更新说明

1. 取消五指上划。五指全部张开并确认约120ms后直接触发一次任务视图，保持张手不反复切换。继续同次手形仍可左右划切换桌面、下划显示/还原桌面一次；明确其他手形0.3秒后开始下一轮。
2. 新增默认开启的“精细定位”：以五点连续同向趋势区分微动与静止抖动，明确微动使用更小死区并保留小数像素；慢速增益0.30，快动仍逐渐加速至1.75。普通响应仍可关闭开关使用，原六项倍率不重置。
3. 减少反向时跨两倍静止死区的空程；进入精细趋势时只采纳新一步，丢弃旧死区/滤波积压，防止突然跳动。停手或趋势不明确时回到静止防抖门槛，不追赶旧速度；非移动轴的噪声不再加快移动轴。
4. 修正滤波起步/忽略帧后的导数时间间隔，减少不同帧率的首段行程差异。指尖相对指根移动、物理鼠标重新锚定、模式/倍率/精细开关切换重新锚定保留。

固定模拟轨迹对比：旧版无法响应的0.004掌宽微动，新版产生两个1像素小步；慢速典型步长约6→3像素；慢速反向首像素约1333→208ms。选定停手加抖动轨迹的累计漂移约15.6→0像素。只反映算法输入重放，不含相机/模型/Windows延迟，不能替代真人精度验收。

左右手、小指只锁定普通光标/拖动、捏合按下释放及超过1秒拖动、滚动默认2×、右击、Ctrl+Q原手势、握拳回中、6项数字框/上下联动和悬浮窗保留。配置仍版本6，旧配置默认启用精细定位，用户关掉后重启保持；无新增模型/相机/应用线程或运行依赖。
